# 跟用户要什么样的提示词

Skill 再好，用户一句"调好看点"就废了。这份是**给用户看的**——他怎么说，你才不用猜。

---

## 四槽公式

```
[哪张] + [哪里不对] + [要什么味道] + [什么不能动]
```

```
snow.jpg      灰雾重、发闷      清冷通透        雪别过曝
  ↑哪张        ↑哪里不对        ↑方向          ↑边界
```

只有第 1、3 槽必需。加上"哪里不对"能少猜一轮；加上"不能动什么"不会把他喜欢的地方改坏。

---

## 三种颗粒度

**微调级**（已有一版，只差一点）——`区域 + 方向 + 幅度`

```
暗部再提一点
天空压回来一些
整体再柔一点，别那么锐
绿色别那么艳
```

**定调级**（原片，最常用）——`场景 + 毛病 + 方向`

```
snow.jpg，雪后古建，灰蒙蒙不通透
想要清冷通透，雪的层次要留住
```

**指派级**（心里已有数值）—— 直接点名参数

```
flower.jpg 曝光 +0.15，高光 -30，阴影 +20，鲜艳度 +8，别加颗粒
```

## 反例对照

| 说了等于没说 | 翻译成 |
|---|---|
| 调好看点 | 灰雾去掉，高光压住 |
| 高级感 | 低饱和、压高光、暗部微提、加颗粒 |
| 电影感 | 青绿暗部 + 暖高光，对比中等，别太锐 |
| 日系 | 整体提亮、低对比、降饱和、偏青 |
| 通透 | 去雾 + 中等对比 + 阴影提亮，别过锐 |
| 自然一点 | 白平衡校正，饱和度不动，不加颗粒 |

抽象词都得翻译，翻译就会错。能说出"哪个部位、往哪偏、偏多少"，基本不用猜。

---

## 四个技巧

**① 负向约束比正向准**

"别让雪发黄"比"雪要白"有效，因为前者直接框住了不该碰的区域。

常用：别把暗部压死 / 雪别过曝 / 别加颗粒 / 肤色别调假 / 对比别太硬。

**② 用参照物代替形容词**

"调成下午四点那种暖"自带一整套参数组合，比"暖一点"精确。

**③ 说清保留什么**

"保留各自曝光，只调颜色"——不说的话默认整张一起动，容易把原本满意的地方改坏。

**④ 不确定就要三版**

```
这张给我三个方向：清冷、暖调、胶片，各出一版小图
```

比来回改十次快。

---

## 反馈的句式

修图是来回，收敛速度全看第二句：`哪里 + 往哪走 + 多少`

```
整体再亮半档，但高光守住
暗部再提一点就停，别发灰
颗粒再加一点点，现在还不够
```

**一次只说一件事。** 一口气提五个，改完谁也不知道是哪个起的作用。

---

## 批量与迁移

```
把 [目录] 统一成 [母版] 的风格，[保留各自曝光 / 完整套用]
参考 [A] 的色调套到 [B]，B 只借颜色，曝光和构图保留自己的
刚才这套参数存成预设，名字叫 [预设名]
```
